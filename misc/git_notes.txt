How to Force Push to Github
1) Make sure local repo is up to date
cd /path/to/your/local/project
git status

2) Stage and commit everything
git add .
git commit -m "Update project structure: Phase I + II + III"

3) Force push to GitHub
git push origin stable/or master --force

*** Forgot to merge with master and stable
Force-pushed stable branch to GitHub, but local main branch hasn’t been updated or merged yet.

1) Check local branches
git branch
git checkout master
git merge stable
git merge --strategy-option theirs stable (If conflict)
git commit -m "merge"

Force updates from github to local
1) git checkout stable

2) git fetch origin
3) git reset --hard origin/stable
verify -->
git status
git log --oneline -1

GITHUB UI MERGE
Pull Request: Base vs. Compare

Base → the branch you want to update / merge into.
Compare (or head) → the branch that has the new changes you want to bring from.

Go to GitHub → your repo → Pull requests → New pull request.

Select:
Base: master
Compare: stable
Review changes → Create PR → Merge PR.
After merging, master will have all the updates from stable.

✅ Key tip:
The base is always the branch that will receive the changes.
The compare/head is the branch that has the new commits.
